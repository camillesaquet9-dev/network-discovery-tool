## Licence

Ce projet est developpe dans le cadre de la SAE 5.01 du BUT Reseaux et Telecommunications de l'IUT de Lannion.

Usage strictement educatif et autorise uniquement sur des reseaux dont vous avez l'autorisation explicite.

## Ressources utilisees

### Bibliotheques Python

- **python-nmap** : Interface Python pour Nmap - https://pypi.org/project/python-nmap/
- **scapy** : Manipulation de paquets reseau - https://scapy.net/
- **netifaces** : Acces aux interfaces reseau - https://pypi.org/project/netifaces/
- **networkx** : Analyse et visualisation de graphes - https://networkx.org/
- **matplotlib** : Generation de graphiques - https://matplotlib.org/
- **lxml** : Traitement XML - https://lxml.de/
- **flask** : Framework web leger - https://flask.palletsprojects.com/

### Outils externes

- **Nmap** : Scanner reseau - https://nmap.org/
- Documentation Nmap NSE scripts : https://nmap.org/nsedoc/

### Projets GitHub d'inspiration

- **python3-nmap** (nmmapper) : Librairie Python 3 pour automatiser les scans nmap avec des methodes Python. Utilisee comme reference pour l'integration nmap. - https://github.com/nmmapper/python3-nmap

- **red-python-scripts** (davidbombal) : Collection de scripts Python pour le hacking ethique incluant un scanner de ports nmap. Inspire la structure du module enveloppe_nmap. - https://github.com/davidbombal/red-python-scripts

- **PenTesting** (Sethlass) : Outil de decouverte reseau et scanner de vulnerabilites utilisant des techniques avancees (ARP, ICMP, TCP SYN). A inspire l'architecture du projet. - https://github.com/Sethlass/PenTesting

### Videos YouTube de reference

- **NetworkChuck - "Nmap Tutorial to find Network Vulnerabilities"** : Tutoriel complet couvrant le scan de ports, mode stealth, detection OS, mode agressif et scripts nmap. Tres utile pour comprendre les bases. - https://www.youtube.com/watch?v=4t4kBkMsDbQ

- **David Bombal - Python Nmap Port Scanner** : Serie de videos montrant comment creer un scanner de ports avec Python et nmap. A inspire l'approche du code Python. - https://www.youtube.com/c/DavidBombal

- **HackerSploit - Penetration Testing Bootcamp** : Bootcamp complet incluant de nombreuses videos sur nmap (timing, NSE, enumeration). Reference pour les options avancees de scan. - https://www.youtube.com/c/HackerSploit

- **IppSec - HackTheBox Walkthroughs** : Walkthroughs detailles de machines HackTheBox avec utilisation intensive de nmap pour l'enumeration. Excellent pour voir nmap en action. - https://www.youtube.com/c/ippsec

- **John Hammond - Cybersecurity & CTF Content** : Tutoriels de pentesting et walkthroughs de CTF utilsant nmap et autres outils. Bonne ressource pour apprendre les techniques. - https://www.youtube.com/c/JohnHammond010

- **Computerphile - Network Security** : Videos educatives sur la securite reseau et informatique. Explications claires des concepts fondamentaux. - https://www.youtube.com/user/Computerphile
